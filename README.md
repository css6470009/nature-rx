# 情绪的自然处方 / Nature Rx

在线访问：https://css6470009.github.io/nature-rx/

一个把“城市自然—情绪”文献证据转成即时处方的移动端交互原型。

## 使用

打开 GitHub Pages 首页，或在手机上访问同一地址。页面为单文件、无构建依赖。

- 定位或手动选择城市
- 选择情绪状态、可用时长、自然偏好与同行者
- 按时间可行性、匹配度与直线距离推荐最近的自然处方
- 提供路线示意、文献线索、备选地点与地图跳转

## 数据说明

- 场景与文献线索来自 257 篇植被—情绪核心文献的复核结果。
- 距离为直线估算，路线为示意，导航以地图应用为准。
- 场景为真实地点或示意点，推荐不等同于论文研究地。
- 定位仅在本地计算，不上传位置。
